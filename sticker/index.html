03Your phone

On the phone, turn on Developer options, USB debugging and Pointer location. Open the custom sticker canvas in HeyTea and note where its edges are on screen, in pixels. These are saved on this device.

Eraser and pen buttons

Where the eraser and pen buttons are, so the script can switch tools by itself. Leave them at 0 to switch by hand when the script asks.

Fast mode: raw touch device

From adb shell getevent -lp: the touchscreen device and its maximum X and Y.

04Draw it

Add an image first.

  1. Connect the phone with USB debugging on, then send the script:
    adb push draw.sh /sdcard/
  2. Open the custom sticker canvas in HeyTea, pick the black pen, and keep the screen on.
  3. Start drawing:
    adb shell sh /sdcard/draw.sh
  4. To stop early, press Ctrl+C in the terminal.
